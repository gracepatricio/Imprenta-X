# Imprenta X – Test Script

| Test Case ID | Feature | Test Objective | Test Steps | Expected Result | Actual Result | Status | Remarks |
|---|---|---|---|---|---|---|---|
| **AUTHENTICATION** |
| TC-001 | Customer Login | Verify a registered customer can log in successfully | 1. Open the app. 2. Enter a valid customer email/ID and password. 3. Tap Login. | Customer is redirected to the Customer Homepage. | | | |
| TC-002 | Employee Login | Verify a registered employee can log in successfully | 1. Open the app. 2. Enter a valid employee ID and password. 3. Tap Login. | Employee is redirected to the Employee Homepage. | | | |
| TC-003 | Admin Login | Verify a registered admin can log in successfully | 1. Open the app. 2. Enter a valid admin ID and password. 3. Tap Login. | Admin is redirected to the Admin Homepage. | | | |
| TC-004 | Login – Invalid Credentials | Verify the app rejects incorrect login credentials | 1. Open the app. 2. Enter an incorrect email/ID or password. 3. Tap Login. | An error message is displayed. User is not logged in. | | | |
| TC-005 | Customer Registration | Verify a new customer can register an account | 1. Open the app. 2. Tap Register. 3. Fill in all required fields with valid data. 4. Tap Submit. | Account is created. A verification email is sent. User is prompted to verify their email. | | | |
| TC-006 | Registration – Duplicate Email | Verify the app rejects registration with an already-used email | 1. Tap Register. 2. Enter an email that already exists in the system. 3. Fill in remaining fields. 4. Tap Submit. | An error message indicating the email is already in use is displayed. | | | |
| TC-007 | Email Verification | Verify the email verification flow works correctly | 1. Register a new account. 2. Open the verification email. 3. Click the verification link. 4. Return to the app. | Account is verified. User can proceed to log in. | | | |
| TC-008 | Forgot Password | Verify a user can reset their password via email | 1. On the Login screen, tap Forgot Password. 2. Enter the registered email address. 3. Tap Submit. | A password reset email is sent to the provided address. | | | |
| TC-009 | Forced Password Change | Verify new employee/admin accounts are forced to change password on first login | 1. Log in with a newly created employee account (temporary password). | A Change Password screen appears that cannot be skipped. User must set a new password before proceeding. | | | |
| TC-010 | Role-Based Access | Verify users cannot access screens outside their role | 1. Log in as a Customer. 2. Attempt to navigate to an Admin or Employee screen via direct route. | Access is denied. User is not shown admin or employee controls. | | | |
| **CUSTOMER – BROWSING & ORDERING** |

| TC-012 | Product Search | Verify the product search/filter works correctly | 1. Navigate to the Products tab. 2. Enter a product name in the search bar. | Only products matching the search query are displayed. | | | |
| TC-013 | Product Category Filter | Verify products can be filtered by category | 1. Navigate to the Products tab. 2. Select a category filter. | Only products belonging to the selected category are shown. | | | |
| TC-014 | Add to Cart | Verify a customer can add a product to their cart | 1. Tap on a product. 2. Select size, quantity, and material. 3. Tap Add to Cart. | The product is added to the cart. The cart item count updates. | | | |
| TC-015 | Cart – Update Quantity | Verify a customer can update item quantity in the cart | 1. Navigate to the Cart. 2. Increase or decrease the quantity of an item. | The item quantity and subtotal update correctly. | | | |
| TC-016 | Cart – Remove Item | Verify a customer can remove an item from the cart | 1. Navigate to the Cart. 2. Remove an item from the cart. | The item is removed. The cart total updates accordingly. | | | |
| TC-017 | Cart – Downpayment Calculation | Verify the cart correctly calculates the 50% downpayment | 1. Add items to the cart. 2. View the Cart screen. | The downpayment displayed equals 50% of the total order amount. | | | |
| TC-018 | Checkout – Online Payment | Verify a customer can complete checkout via PayMongo | 1. Add items to the cart. 2. Tap Checkout. 3. Select online payment. 4. | TC-019 | Checkout – Payment Confirmation | Verify the order status updates after successful payment | 1. Complete an online payment. 2. Navigate to My Orders. | The order appears with status "Pending" after payment is confirmed. | | | |
| TC-020 | File Upload on Order | Verify a customer can upload a design file with their order | 1. Start an order customization. 2. Tap Upload File. 3. Select an image or PDF from the device. | The file is uploaded successfully and attached to the order. | | | |
| **CUSTOMER – ORDER TRACKING & COMMUNICATION** |

| TC-024 | Customer Chat | Verify a customer can send a message about an order | 1. Open an active order. 2. Tap the chat icon. 3. Type a message and send. | The message is sent and visible in the chat thread. | | | |
| TC-025 | Awaiting Payment Order | Verify awaiting payment orders are visible to the customer | 1. Place an order but do not complete payment. 2. Navigate to My Orders. | The order appears under the "Awaiting Payment" filter. | | | |
| **EMPLOYEE – JOB QUEUE** |
| TC-026 | View Job Queue | Verify an employee can view the production job queue | 1. Log in as an employee. 2. Navigate to the Job Queue. | All pending/active/ready jobs are listed in order of priority. | | | |
| TC-027 | Mark Order as In Production | Verify an employee can advance an order to In Production | 1. Open a Pending order in the Job Queue. 2. Tap Mark as In Production. | The order status changes to "In Production". The customer's order view reflects the update. | | | |
| TC-028 | Mark Order as Ready | Verify an employee can mark a completed order as Ready for pickup | 1. Open an In Production order. 2. Tap Mark as Ready. | The order status changes to "Ready". | | | |
| TC-029 | Mark Order as Completed | Verify an employee can mark a collected order as Completed | 1. Open a Ready order. 2. Tap Mark as Completed. | The order status changes to "Completed". | | | |
| TC-030 | Cancel Order | Verify an employee can cancel an order | 1. Open an active order in the Job Queue. 2. Tap Cancel Order. 3. Confirm cancellation. | The order status changes to "Cancelled". | | | |
| TC-031 | Employee Chat with Customer | Verify an employee can reply to a customer message | 1. Open an order with a pending customer message. 2. Tap the chat thread. 3. Type a reply and send. | The reply is sent and visible to both the employee and customer. | | | |
| **EMPLOYEE – POINT OF SALE (POS)** |
| TC-032 | Search Customer in POS | Verify an employee can search for a customer by name or ID | 1. Navigate to the POS screen. 2. Enter a customer name or ID in the search bar. | The matching customer appears in the search results. | | | |
| TC-033 | View Customer Orders in POS | Verify active orders appear when a customer is selected | 1. Search and select a customer in the POS. | All active (pending, in production, ready) orders for that customer are listed with their balance. | | | |
| TC-034 | Collect Cash Payment | Verify an employee can collect a cash payment for an order | 1. Select a customer with an outstanding balance. 2. Tap on an order. 3. | TC-035 | POS – Minimum Downpayment Rule | Verify the POS enforces the 50% minimum downpayment | 1. Open a new order (₱0 paid) in the POS. 2. Enter an amount below 50% of the total. 3. | TC-036 | POS – View Invoice | Verify an employee can view the invoice for an order from the POS | 1. Select a customer in the POS. 2. On an order card, tap Invoice. | The invoice PDF for that order opens. | | | |
| **EMPLOYEE – INVENTORY** |
| TC-037 | View Inventory | Verify an employee can view the current inventory stock | 1. Log in as an employee. 2. Navigate to Inventory. | All raw materials are listed with their current stock levels and units. | | | |
| TC-038 | Scan Barcode / QR Code | Verify an employee can scan a barcode or QR code to identify inventory items | 1. Navigate to Inventory. 2. Tap the scan button. 3. Scan a valid item barcode/QR code. | The corresponding inventory item is identified and its details are shown. | | | |
| TC-039 | Inventory Deduction on Production | Verify raw materials are automatically deducted when an order moves to In Production | 1. Note the stock levels of materials used by a product. 2. | TC-040 | Low Stock Notification | Verify a notification is sent when a material stock falls below the threshold | 1. Set a material's stock close to the low-stock threshold. 2.
